# Задержка

Сюжетная стратегия для лаунчера Sevensave. Ты пилот единственного спасательного буксира на сектор. Четырнадцать сигналов бедствия, двенадцать мест, сто единиц топлива, двадцать один день. Курс посчитан по данным первых суток, рейс длится три недели: курс приходится чинить на ходу — скоростью, сливом топлива со станций, распоряжением «экономия». Каждый голос, который ты слышишь, уже прошлое.

Готовые сборки для macOS (Apple Silicon и Intel) и Windows x64 доступны в [релизах](https://github.com/sevensave/zaderzhka/releases/latest). Исходный код содержит сюжетные спойлеры.

## Запуск

```bash
npm ci
npm run web        # в браузере: http://localhost:5311
npm run dev        # в окне Electron
npm test           # проверки симуляции и интерфейса
node tools/balance-v2.mjs   # перебор баланса 2.0
npm run typecheck
npm run pack       # zip под macOS (arm64, x64) и Windows x64 + проверка имён и подписи
```

## Устройство

- `src/sim/` — мир (`world.ts`: станции, режимы, курс Веры, контрольные точки) и симуляция (`engine.ts`): шаг «Дальше» до ближайшей остановки, сеансы со скоростью света, отклонения воздуха, тишина, статусы, журнал, планировщик, слив, экономия, ретранслятор, финал. Без DOM.
- `src/content/` — весь текст: сеансы станций и три ветки ответов (`stations.ts`), 33 файла Веры и 15 дублей (`vera.ts`), строки интерфейса (`ui-text.ts`), вечерние реплики пилота (`evenings.ts`), люди (`people.ts`), бортовой журнал (`board.ts`), сцены и эпилоги (`scenes.ts`).
- `src/ui/` — пиксельный слой 480×270 на canvas (`scene.ts`), рубка, пульт и плоттер (`app.ts`), экраны поверх пульта (`panels.ts`), процедурный звук (`audio.ts`).
- `src/main/`, `src/preload/` — окно Electron, сохранения в `userData/saves`, проверка версии.

## Sevensave

Архивы `Zaderzhka-<версия>-mac-arm64.zip`, `Zaderzhka-<версия>-mac-x64.zip`, `Zaderzhka-<версия>-win-x64.zip`, внутри `Zaderzhka.app` и `Zaderzhka.exe` — ровно как в записи каталога лаунчера. Под `SEVENSAVE_LAUNCHER=1` игра не спрашивает GitHub о новых версиях.

Шрифты Pixelify Sans, IBM Plex Mono и PT Serif — OFL, лицензии в `resources/licenses/`.
